# Demo Files

This directory contains example files for testing the Monaco Editor integration.

## Files

- `example.ts` - TypeScript example with classes and interfaces
- `example.py` - Python example (coming soon)
- `example.go` - Go example (coming soon)
- `example.rs` - Rust example (coming soon)

## Testing

1. Open the File Explorer in Cortex IDE
2. Navigate to this directory
3. Click on any file to open it in the editor
4. Test features:
   - Syntax highlighting
   - IntelliSense / autocomplete
   - Find & Replace (Ctrl+F / Cmd+F)
   - Multiple tabs
   - Save (Ctrl+S / Cmd+S)
   - Close tabs (Ctrl+W / Cmd+W)
