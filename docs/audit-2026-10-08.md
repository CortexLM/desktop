# Desktop architecture and interaction audit

Fresh GitHub baseline: `e6028e5c`. One desktop PR accompanies the backend audit
PR. No merge or deployment is part of this work.

## Confirmed corrections

- Glob/grep enforce read permission on roots and discovered files. Canonical
  paths and nearest existing parents prevent symlink escapes from bypassing
  external-directory permission.
- Child sessions inherit parent-agent deny rules; plan delegation cannot turn
  into a write. Connected MCP tools default to ask before explicit overrides.
  Computer-use observation requires a leading observation verb, not an action
  name containing an app/window noun. Enabled skills expose selectable names.
- Bot/task PATCH leaves omitted defaults absent, preserving permission,
  persona, tool filter, mascot and paused scheduled-task state.
- Native call starts fence pending authentication and ownership. Hangup can
  cancel a pending start without acquiring another window's call controls.
- Browser loopback bodies count bytes and decode UTF-8 once, preserving split
  multibyte sequences and the existing browser-read output limit.
- Unreadable credentials cannot prevent window creation or erase ciphertext.
  A rotated pair survives transient identity reads without promoting an
  unverified account. Native logout accepts the producer's 200 response.
- Renderer event subscriptions reconnect and release their resources; cached
  queries and transcripts resync. Code watches use the SDK reconnect policy
  and refresh on each accepted connection. Missing-ID Chat redirects replace
  history rather than trapping Back.
- Refused deferred Chat deletion restores the route and shows an error. The
  four-second Undo grace remains uncommitted until the toast closes.
- Locale key parity is bidirectional; tests no longer overwrite tracked browser
  connector screenshots. SDK 0.4.9/API types 0.3.8 adopt backend stream/audio fixes.

## Verification

Actual built Electron passed 239 end-to-end scenarios under Xvfb, including
owner transitions, auth, live chat, streaming and work flows. Subsequent targeted
checks covered later changes. The source integration suite passed 509 tests with
one optional skip, types/lint clean and no i18n audit problems. The final
forced-DELETE-500 Electron case restored the Chat and showed an error, with
types/lint clean. CI evidence must match the latest pushed SHA.

Native auth used real loopback transport. Corrupt-store boot opened an actual
Electron window signed out, preserving the corrupt bytes. Shared resampling
passed exact 44.1/48 kHz segmented-versus-contiguous signal tests; Chromium
verified actual microphone capture, worklet setup and playback credit.

Current rendered Chat redirects were inspected at 960x640 and 1440x900 in
light/dark themes after fonts and finite animations settled. No stable blank,
overlap or horizontal overflow appeared. Older early captures were rejected
as readiness failures, not counted as product failures.

## Decisions and acceptance boundaries

Undo deletion follows the existing History contract: DELETE occurs on toast
close. Window shutdown during the grace cancels an uncommitted deletion. The
toast alone never establishes durable deletion. The alleged pending Code-title
defect had no current source/probe evidence and was not retained.

Foreign tracked pairing screenshots are excluded from this change. Unselected
intermediate SDK archives are excluded; previous tracked archives remain for
provenance, while manifests select only the current pair.

Linux Electron checks are not signed macOS/Windows package or real-user provider
acceptance. Actual deployed Bot voice/device/farm availability remains outside
the controlled test evidence. A finite audit cannot prove no unknown bugs remain.
