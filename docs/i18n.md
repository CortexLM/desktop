# Internationalisation

## Catalogs

`packages/i18n/locales/<locale>/<namespace>.json` — flat `key → string` per namespace.
Keys are addressed as `<namespace>.<key>` (`t("chat.noProvider.title")`).

- **English (`en`) is the source.** Every user-facing string in `packages/app/src` and
  `packages/desktop/src` is a key read through `t()`.
- Declared locales (`LOCALES` in `packages/i18n/src/index.ts`): `en fr es de ja zh-Hans
  pt-BR ko`, matching the backend's locale list (asserted by `tests/unit/locales.test.ts`).
- Catalogs present today: `en` and `fr` only. Missing keys fall back to English, then to
  the key itself.
- Plurals: `key_one`, `key_other`, … selected with `Intl.PluralRules` when `vars.count` is
  a number. Placeholders: `{name}`.

## Loaders

| Host | Loader |
| --- | --- |
| Renderer (Vite) | `@cortex/i18n/vite` — `import.meta.glob` of `locales/*/*.json` |
| Main, scripts, tests | `@cortex/i18n/node` — `nodeCatalogs(dir)` |

Renderer locale: `localStorage["cortex.locale"]`, then `navigator.languages`; switchable in
Settings → Appearance. Native menu (`packages/desktop/src/menu.ts`): `CORTEX_LOCALE`, then the
OS preferred languages. Packaged builds read `resources/locales`.

## Fixtures

`packages/i18n/locales/<locale>/fixtures/<area>.json` holds preview content (names, rows,
sample text) so the gallery is translatable. Loaded only in preview
(`packages/app/src/preview.tsx`); excluded from packaged builds.

## Tooling

- `bun run audit:i18n` (`scripts/audit-i18n.mjs`): fails on literal copy in JSX text,
  user-facing attributes (`aria-label`, `title`, `placeholder`, `alt`, …), toast/label
  object keys and menu `label:` literals, and on `t()` keys missing from English.
- `tests/unit/locales.test.ts`: every non-English locale has every English key with the
  same placeholders. It fails today for the six locales without catalogs and for `fr`
  where keys are missing — run the translator.
- `node scripts/translate-locales.mjs [--only <ns>] [--force]` with `TRANSLATE_BASE_URL`,
  `TRANSLATE_API_KEY`, optional `TRANSLATE_MODEL` (any OpenAI-compatible endpoint). Sends
  only missing or changed keys (tracked in `.source.json` files), verifies placeholders,
  never translates product names.
