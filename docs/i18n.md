# Internationalisation

## Catalogs

`packages/i18n/locales/<locale>/<namespace>.json` — flat `key → string` per namespace.
Keys are addressed as `<namespace>.<key>` (`t("chat.noProvider.title")`).

- **English (`en`) is the source.** Every user-facing string in `packages/app/src` and
  `packages/desktop/src` is a key read through `t()`.
- Declared locales (`LOCALES` in `packages/i18n/src/index.ts`): `en fr es de ja zh-Hans
  pt-BR ko`, matching the backend's locale list (asserted by `tests/unit/locales.test.ts`).
- All eight locales have 13 namespace catalogs and seven preview fixture files. Missing
  keys still fall back to English, then to the key itself.
- The frozen Components catalog uses its own `components` namespace, including specimen
  labels, controls, family descriptions and motion explanations in all eight locales.
- Plurals: `key_one`, `key_other`, … selected with `Intl.PluralRules` when `vars.count` is
  a number. Placeholders: `{name}`.

## Runtime copy

- Mascot accessible names translate the state and the `common.mascotLabel` format.
- `packages/app/src/state/tool-label.ts` maps built-in tool IDs to catalog labels;
  extension tool names, paths and command text remain data. Todo titles use the structured
  input list and catalog plurals, never the engine's English title. Failed or interrupted
  tools show generic catalog copy; the Code terminal does not render raw tool errors.
- Routine durations use the translated seconds unit. Settings/composer model context
  sizes and composer currency use the selected locale's number format.
- `tests/unit/runtime-copy.test.ts` checks rendered mascot accessibility and Code tool
  copy across all eight locales. It is a targeted regression, not whole-program coverage.
- New untitled sessions store an empty title. Legacy English defaults cannot be distinguished
  from user-authored titles, so existing titles remain intact and may need manual renaming.

## Loaders

| Host | Loader |
| --- | --- |
| Renderer (Vite) | `@cortex/i18n/vite` — `import.meta.glob` of `locales/*/*.json`, excluding `*.source.json` |
| Main, scripts, tests | `@cortex/i18n/node` — `nodeCatalogs(dir)`, excluding `*.source.json` |

Renderer locale: `localStorage["cortex.locale"]`, then `navigator.languages`; switchable in
Settings → Appearance. Native menu (`packages/desktop/src/menu.ts`): `CORTEX_LOCALE`, then the
OS preferred languages. Packaged builds read `resources/locales`.

## Fixtures

`packages/i18n/locales/<locale>/fixtures/<area>.json` holds preview content (names, rows,
sample text) so the gallery is translatable. Loaded only in preview
(`packages/app/src/preview.tsx`); Vite includes these lazy modules in renderer builds.
Their presence in a package does not seed live engine data.

## Packaging and acceptance limits

- `electron-builder.yml` excludes `**/*.source.json` and `**/fixtures/**` from the raw
  `resources/locales` copy. Source stamps are translation bookkeeping, not application copy.
- Vite catalog/preview globs and the Node catalog filter exclude `*.source.json`; source
  stamps are not runtime catalogs or preview modules. Rebuild renderer and desktop before
  packaging so stale assets cannot retain earlier stamp content.
- Catalog parity checks keys and placeholders in namespace files; it does not validate
  fixture translation quality, linguistic accuracy or layout across all eight locales.
  The screen-render sweep is not an eight-locale visual review.

## Tooling

- `bun run audit:i18n` (`scripts/audit-i18n.mjs`): fails on literal copy in JSX text,
  user-facing attributes (`aria-label`, `title`, `placeholder`, `alt`, …), toast/label
  object keys and menu `label:` literals, and on `t()` keys missing from English. It follows
  local constants, literal `.map()` values, casing calls and expression branches;
  source stamps do not satisfy missing keys.
  This static regression guard does not trace imported values, function results, runtime
  object lookups or dynamic translation keys; a zero-finding result is not complete dataflow proof.
- `tests/unit/locales.test.ts`: every non-English locale has every English key with the
  same placeholders; the Node loader excludes source-stamp namespaces. Consult the run
  result for the tested revision; catalog presence alone is not a passing-test claim.
- `node scripts/translate-locales.mjs [--only <path-prefix>] [--loc <locale>] [--force]` with `TRANSLATE_BASE_URL`,
  `TRANSLATE_API_KEY`, optional `TRANSLATE_MODEL` (any OpenAI-compatible endpoint). Sends
  selected missing/changed entries, handles nested fixtures while preserving identifier
  fields, verifies returned placeholders and instructs the translator to preserve product
  names. `*.source.json` records translated English inputs; review output before accepting it.
