# Screenshots Directory

This directory contains automated visual regression test screenshots.

## Structure

```
screenshots/
├── index.html              # Interactive HTML report
├── *.png                   # App-level screenshots
├── components/             # Isolated component screenshots
├── storybook/              # Storybook-style documentation
└── comparison/             # Visual diff results
    ├── comparison-report.html
    └── diff-*.png
```

## Files

Screenshots follow this naming convention:
```
{component}__{theme}__{state}__{viewport}.png
```

Examples:
- `git-panel__dark__default__desktop.png`
- `button__light__hover__laptop.png`
- `ai-chat__dark__loading__wide.png`

## Generated Files

All files in this directory are automatically generated by:
```bash
bun run screenshots:capture
```

**Do not commit these files to git** (they are in .gitignore)

## Viewing

Open `index.html` in a browser to view all screenshots with filtering and full-screen preview.

```bash
bun run screenshots:view
```
