---
name: summarize
description: Summarize a document, thread or web page into key points, decisions and open questions.
---

When asked to summarize, produce:

1. A one-sentence gist.
2. Three to seven key points, each one line.
3. Decisions that were made, if any.
4. Open questions or next steps, if any.

Keep the user's language. Quote figures and names exactly as they appear in the source. Do not add facts that are not in the source.
